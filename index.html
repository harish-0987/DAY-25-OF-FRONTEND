JavaScript Loops

A clean and simple introduction to repetition in JavaScript using basic for, while, do...while, and for...of loops.

1. for Loop

Classic Counting Loop

Repeats a block of code a specific number of times using an index variable.

Running loop...
// for (initialization; condition; increment)
for (let i = 1; i <= 5; i++) {
    console.log("i = " + i);
}
2. while Loop

Condition-Based Countdown

Executes repeatedly as long as the specified condition evaluates to true.

Running countdown...
let count = 5;
while (count > 0) {
    console.log(count);
    count--; // decrement to avoid infinite loop
}
3. do...while Loop

Runs At Least Once

Always executes the block once before evaluating the condition.

Click an option above...
let val = 10;
do {
    // Executes once even though 10 <= 5 is false!
    console.log("val = " + val);
    val++;
} while (val <= 5);
4. for...of & Control

Array Iteration & Flow

Iterates over iterable values (arrays) and controls flow using break & continue.

Click a button above...
const fruits = ["🍎 Apple", "🍌 Banana", "🍊 Orange"];
for (const item of fruits) {
    if (item === "🍌 Banana") continue; // skip
    if (item === "🍊 Orange") break;    // stop
    console.log(item);
}
