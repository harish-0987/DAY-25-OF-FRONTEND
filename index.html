JavaScript Functions

A clean and simple introduction to writing reusable code with Function Declarations, Expressions, Arrow Functions, and Default Parameters.

1. Function Declaration

Named Function (Hoisted)

Declared with the function keyword. Can be invoked anywhere in the scope, even before declaration.

Ready...
// Function Declaration
function greetUser(name) {
    return `Hello, ${name}! Welcome to Day 23.`;
}

greetUser("Harish"); // Hoisted & callable
2. Function Expression

Anonymous Function Variable

An anonymous function assigned to a variable. Not hoisted; must be defined before invocation.

Ready...
// Function Expression
const calculateArea = function(width, height) {
    return width * height;
};

calculateArea(6, 4); // Returns 24
3. Arrow Function (ES6)

Modern Concise Syntax

Compact arrow syntax => ideal for quick computations and cleaner, modern JavaScript code.

Ready...
// ES6 Arrow Function
const calculateDiscount = (price, discountPercent) => {
    const discountAmount = (price * discountPercent) / 100;
    return price - discountAmount;
};

calculateDiscount(120, 20); // Returns 96.00
4. Default Parameters

Fallback Argument Handling

Assign default fallback values directly in the parameter list to safeguard against missing arguments.

Ready...
// Default Parameters
function createProfile(user = "Guest User", role = "Explorer") {
    return { user, role };
}

createProfile(); // Uses "Guest User" & "Explorer"
5. Return vs. Void (Console)

Output Values & Reusability

A return statement passes computed data back to the caller for storage or reuse. Functions without return evaluate to undefined.

Click a button above...
// With Return (Usable output)
function addWithReturn(a, b) {
    return a + b; // Storable in variable!
}

// Without Return (Void / Console only)
function addWithoutReturn(a, b) {
    console.log(a + b); // Returns undefined
}
