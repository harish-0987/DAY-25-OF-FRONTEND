Day 25 of 100 Days Frontend

JavaScript DOM Manipulation

A clean, beginner-friendly introduction to interacting with web pages dynamically using document methods, content updates, styles, dynamic elements, and event listeners.

1. Content Manipulation

textContent vs innerHTML

textContent handles raw text safely; innerHTML parses and renders HTML tags inside elements.

Initial Target Text
Ready...
const el = document.getElementById("content-target");
// 1. Plain text (safe from XSS)
el.textContent = "New text";

// 2. HTML rendered markup
el.innerHTML = "<strong>Bold</strong> text";
2. Styles & Classes

Inline Styles & classList

Control appearance via element.style properties or toggle CSS classes with element.classList.toggle().

Dynamic Style Box
Ready...
const box = document.getElementById("style-target");
// Change style
box.style.color = "#38bdf8";

// Toggle class
box.classList.toggle("highlight-active");
3. Dynamic Elements

createElement & appendChild

Create elements in memory, configure attributes, append them to the DOM, or remove them on the fly.

Ready...
// 1. Create element
const chip = document.createElement("span");
chip.textContent = "New Item";

// 2. Append to parent
container.appendChild(chip);

// 3. Remove element
chip.remove();
4. Attributes

setAttribute & getAttribute

Inspect and change HTML tag attributes dynamically, such as input type, placeholder, or src.

Ready...
const input = document.getElementById("attr-input-demo");

// Get and Set attribute
const current = input.getAttribute("type");
input.setAttribute("type", "text");
input.setAttribute("placeholder", "New text...");
5. Event Listeners

addEventListener (Click & Input)

Attach listeners to react immediately when users click buttons, type into text fields, or move the mouse.

0 clicks
(Waiting for input...)
Waiting for user interaction...
// Click Listener
btn.addEventListener("click", () => {
    counter++;
    counterDisplay.textContent = `${counter} clicks`;
});

// Input Listener (real-time typing)
input.addEventListener("input", (event) => {
    output.textContent = event.target.value;
});
