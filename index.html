JavaScript Array & String Methods

A clean, beginner-friendly exploration of fundamental methods for manipulating text (String) and collections (Array).

1. String Methods

Case & Whitespace Cleanup

Strings are immutable. Methods return a fresh new string without altering the original text.

Ready...
const text = "   Hello JavaScript!   ";
text.toUpperCase(); // "   HELLO JAVASCRIPT!   "
text.toLowerCase(); // "   hello javascript!   "
text.trim();        // "Hello JavaScript!"
2. String Methods

Search & Replace

Check for substrings with includes(), locate positions with indexOf(), and swap words with replace().

Ready...
const str = "JavaScript is awesome";
str.includes("Script"); // true
str.indexOf("Script");  // 4
str.replace("awesome", "powerful"); // "JavaScript is powerful"
3. Array Methods

Add & Remove Elements

Arrays are mutable lists. push & pop work on the end; unshift & shift work on the beginning.

Ready...
const fruits = ["🍎 Apple", "🍌 Banana"];
fruits.push("🍊 Orange");       // Added to end
fruits.pop();                   // Removed from end
fruits.unshift("🍓 Strawberry");// Added to start
fruits.shift();                 // Removed from start
4. Array Methods

Search, Slice & Reverse

Query items, take shallow copies using slice(), or flip element order with reverse().

Ready...
const list = ["🍎 Apple", "🍌 Banana", "🍊 Orange"];
list.includes("Apple");          // true
const copy = list.slice(0, 2);   // ["🍎 Apple", "🍌 Banana"]
list.reverse();                  // Reverses original list
5. The Bridge

Converting Strings ⇄ Arrays (split & join)

Use split(delimiter) to break a string into an array, and join(delimiter) to glue an array into a string.

Click an option above...
// 1. String to Array:
const skills = "HTML,CSS,JavaScript".split(","); // ["HTML", "CSS", "JavaScript"]

// 2. Array to String:
const combined = skills.join(" - "); // "HTML - CSS - JavaScript"

// 3. String Reversal Pattern:
const reversed = "hello".split("").reverse().join(""); // "olleh"
