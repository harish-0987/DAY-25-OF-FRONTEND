JavaScript Conditional Statements

A clean and simple introduction to decision-making in JavaScript using basic if, else, else if, switch, and ternary operator.

1. if...else

Age Eligibility Checker

Checks if a person is eligible to vote based on age (18+).

Result will appear here...
if (age >= 18) {
    return "Eligible to vote! 🗳️";
} else {
    return "Not eligible yet (18+ required). ⏳";
}
2. if...else if...else

Student Grade Calculator

Evaluates academic performance score (0-100) into letter grades.

Result will appear here...
if (marks >= 90) return "Grade A+ 🌟";
else if (marks >= 75) return "Grade A 👍";
else if (marks >= 50) return "Grade B 👌";
else return "Grade F (Fail) ❌";
3. switch statement

Traffic Signal Controller

Select a signal color to see the required driver action.

Click a signal above...
switch (color) {
    case "Red": return "STOP! 🛑";
    case "Yellow": return "GET READY! ⚠️";
    case "Green": return "GO! 🟢";
    default: return "Unknown signal ❓";
}
4. Ternary Operator (? :)

Login Status Toggle

Compact one-line conditional statement for binary decisions.

Status: Logged Out
Please log in to continue. 🔒
// condition ? exprIfTrue : exprIfFalse
let message = isLoggedIn 
    ? "Welcome back, User! 👤" 
    : "Please log in to continue. 🔒";
